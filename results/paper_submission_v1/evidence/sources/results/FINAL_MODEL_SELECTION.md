该模型使用 F=16、latent=4 的原骨干与相关解码，保留地图、空间和事件训练目标；没有加入 coherent 的 9×9 类别噪声改动。数据为 100 训练 / 25 校准 / 40 验证父地点，每地点一个观测、五来源均衡，515 查询及 0/10/20 格半径合计 1545 个事件。最多 24 epoch / 600 更新，只能称小规模开发实验。2/100 个无查询训练地点造成的旧事件微批加权限制必须保留披露；不能声称它采用了后来正式协议的加权修复。

在该同条件三种子表中，原 ConPath / independent / 确定性网络的 K32（确定性 K1）Brier 分别为 0.103799 / 0.112011 / 0.111516；30% 覆盖风险为 23.95% / 24.43% / 25.16%；隐藏可通行类 IoU 为 0.62238 / 0.62120 / 0.66228。原模型相对确定性网络的 Brier 差值区间 [-0.01616, 0.03377] 跨零，地图 IoU 也低于确定性网络。故没有全面指标优势。

从相同保存预测补算的事后诊断进一步限定这个选择。原 ConPath 的 Event NLL / ECE 为 0.79330 / 0.08622；已有训练集拟合半径先验的 NLL / ECE 更低，为 0.48499 / 0.05653，但其 Event Brier 为 0.15606，且置信度 0.8 时覆盖率为零，false-safe 未定义，不能记成零风险。连续概率估计下，确定性网络的隐藏地图 Brier 为 0.138685，优于原 ConPath 的 0.151468 和 independent 的 0.151580；不能用确定性模型较差的阈值后二值地图 Brier 来制造概率地图质量优势。

在同一当前三种子 K32 预测中，置信度 0.8 时原 ConPath 的平均 false-safe 为 18.6494%、覆盖率 21.3400%；independent 为 20.8473%、22.4533%。这是不同覆盖率的阈值比较，不是相同覆盖下的安全优势，也不是上面的 30% 覆盖风险。NLL / ECE / 0.8 汇总均为事后描述，没有用于重新选择模型、epoch、seed 或阈值，不伪称原父级协议注册指标。完整数值、估计器区别、空值及来源见 [最终数字快照](paper_validation_snapshot.json)。
