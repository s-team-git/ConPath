# Results

Generated checkpoints, predictions, calibration curves, and tables belong here and are ignored
by Git. A result is paper-valid only when its dataset version, split, configuration, checkpoint,
and command are recorded together.

The first local P0 artifacts are generated by:

```bash
PYTHONPATH=src .venv/bin/python scripts/evaluate_p0.py --output-dir results/p0_death_test
PYTHONPATH=src .venv/bin/python scripts/benchmark_merge_tree.py --output results/merge_tree_benchmark.json
```

`P0_DEATH_TEST.md` records the default metrics and the conservative neural/public-data gate. The
correlated row is an oracle synthetic diagnostic; it is not a trained neural result.
