ConPath: Connectivity-Calibrated Path Reliability

Event-level calibration of footprint-conditioned connectivity under partial observation

A reproducible research prototype for uncertainty-aware geometric planning

▣ Paper draft ⌘ Code ↗ TUM RGB-D ↓ Results
Scope. The hero is generated from trained neural checkpoints, not illustrative or synthetic media. Under the corrected valid-support training contract, scene-weighted Brier is 0.06749 ± 0.00936 for ConPath versus 0.09521 ± 0.00703 for the independent control; independent-minus-ConPath is +0.02772 ± 0.00993, with positive paired bootstrap intervals for all three seeds. This remains validation-only on a non-official provenance split: the physical test and cross-domain publication gates are still closed. The TUM RGB-D geometry video is retained below as a separate pipeline pilot.

Abstract

Occupancy marginals do not answer the question a robot asks at planning time: is there a support-valid path from a start to a goal for my footprint? ConPath treats that question as a calibrated event. A stochastic posterior produces spatially coherent support-map hypotheses, and a footprint-aware connectivity operator evaluates the event on each hypothesis rather than multiplying independent cell probabilities. The primary visual now exposes that model-level comparison on a frozen, scene-disjoint FlatLands validation protocol; a separate TUM RGB-D sequence keeps the RGB-D → world-geometry hand-off inspectable.

An audit found that invalid cells outside the epistemic support were not hard-blocked in an earlier forward. The old checkpoints and their post-hoc correction are retained as an audit trail; the primary visual now uses the independently audited clean-support rerun. No FlatLands test labels have been opened, and the non-official provenance split still limits the claim to validation.

Method

From a partial bird's-eye-view observation to the probability that a vehicle-sized path exists.

1Observefree / blocked / unknown input
2Imaginecorrelated posterior worlds
3Account for sizeerode by robot footprint
4Decidecalibrated path probability
01

Encode partial observations

The model reads observed free, blocked, and unknown cells in a bird's-eye-view grid. Cells outside the valid support domain remain blocked throughout training and prediction.

02

Sample joint worlds

A learned mean map, global latent factors, and locally correlated noise produce complete map hypotheses. The independent control uses the same encoder, parameter budget, observations, and queries.

03

Score the event

Each sampled world is eroded by a disk footprint and queried with four-neighbour connectivity. Brier, NLL, ECE, and false-safe rate attach calibration to the planning event.

What the controlled experiments show

Spatial dependence changes event accuracy, while the strongest deterministic control and equal-coverage risk qualify the result.

Fixed marginals. Independently shuffling the world index at every cell preserves each empirical occupancy probability exactly, but event Brier rises from 0.06749 to 0.16139. The same-checkpoint mean map reaches 0.06957, so the stochastic advantage over deterministic thresholding is small and reverses in one seed. The shuffle is an evaluation intervention, not a retrained architecture ablation.

These real UnScenes3D panels use the correlated clean checkpoint and show the camera/LiDAR projection, observed BEV, posterior mean, and footprint-conditioned reachability. The second panel is deliberately a false-safe validation failure: the visual makes the remaining calibration limitation visible instead of implying a win.

Why this adapter is limited. An exact audit of optimistic and pessimistic completions finds an observation-conditioned Brier lower bound of 0.47574 on validation, compared with current model Brier 0.51142. Only 15.66% of validation events can change through unknown-cell completion. The remaining events are already determined by hard observations and support. This identifies a constraint of the frozen adapter; it is not a universal limit on the dataset or on better sensor models.

Reproducibility and limits

Run the pilot

/usr/bin/python3 scripts/run_tum_rgbd_pilot.py \
  --publish-site

Raw data stays in the ignored data/raw/ directory. The command writes the report, CSV, figures, and the compact real-data video used on this page.

Claim boundary

This pilot has no human or robot collision labels. Its connectivity labels are defined on a fused geometric reference map. It is evidence that the real-data path runs end to end, not evidence that ConPath is already ready for ICRA/IROS.
