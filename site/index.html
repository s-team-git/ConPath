ConPath: Connectivity-Calibrated Path Reliability

Event-level calibration of footprint-conditioned connectivity under partial observation

A reproducible research prototype for uncertainty-aware geometric planning

▣ Paper draft ⌘ Code ↗ TUM RGB-D ↓ Results
Scope. This page reports a real RGB-D geometric reference-map pilot. TUM supplies RGB/depth and camera motion, not traversability or collision labels; the numbers below are not a public navigation benchmark or a validated neural P0 result.

Abstract

Occupancy marginals do not answer the question a robot asks at planning time: is there a support-valid path from a start to a goal for my footprint? ConPath treats that question as a calibrated event. A stochastic posterior produces spatially coherent support-map hypotheses, and a footprint-aware connectivity operator evaluates the event on each hypothesis rather than multiplying independent cell probabilities. This project page makes the data path inspectable with a real RGB-D sequence: sampled depth pixels are lifted with the official Freiburg-1 intrinsics and motion-capture poses, fused into a horizontal world-frame reference raster, and evaluated on future-frame queries.

The current real-data result is intentionally a pilot. It validates the RGB-D → world geometry → event-audit path, while a paper-grade navigation claim still requires auditable traversability labels, a trained neural checkpoint, and sequence/site-held-out public benchmarks.

Method

From partial RGB-D evidence to a task-level connectivity probability.

1Observefree / blocked / unknown input
2Imaginecorrelated posterior worlds
3Account for sizeerode by robot footprint
4Decidecalibrated path probability
01

Lift and fuse

Registered depth is back-projected with the TUM Freiburg-1 camera model and transformed by the official MoCap pose. Repeated support-height returns form a geometric reference raster.

02

Sample joint worlds

Unknown cells retain uncertainty. The pilot compares independent-cell completion with a spatially correlated temporal random field clamped by observed evidence.

03

Score the event

Each sampled world is eroded by a disk footprint and queried with four-neighbour connectivity. Brier, NLL, ECE, and false-safe rate attach calibration to the planning event.

Recent-method budget check (validation-only). The PaSCo-inspired three-subnet adapter is stable as the total event sample budget increases: Brier is 0.22898 (K=32), 0.22842 (K=64), and 0.22806 (K=128); NLL changes from 2.89817 to 2.84268. This is a same-contract uncertainty control, not a reproduction of PaSCo's 3-D model or a final leaderboard claim. Download K-sensitivity snapshot ↗
New causal control (validation-only). A three-seed F=16 independent decoder with the same K=32 event contract scores Brier 0.11214 ± 0.00306, compared with ConPath 0.09607 ± 0.01222. Removing spatial correlation therefore degrades the connectivity event score; this is a diagnostic control, not a final paper claim. Download the control snapshot ↗
Mean-map diagnostic (validation-only). Thresholding the ConPath posterior mean map gives event Brier 0.07111 ± 0.00377, but hidden-map Brier rises to 0.17842 ± 0.00512 and the event becomes binary. This trade-off is why the final method retains stochastic posterior samples. Download mean-map snapshot ↗
Uncertainty diagnostics (validation-only). The reliability and selective-risk curves below reuse the exact same three seeds and 4,653 frozen events. ConPath reaches false-safe rate 0.060 ± 0.014 at the 0.8 threshold with 0.291 ± 0.016 coverage; the independent decoder is higher-risk at 0.074 ± 0.003. The binary mean-map control has larger false-safe rate (0.117 ± 0.006) despite its lower event Brier. Download calibration snapshot ↗

Reproducibility and limits

Run the pilot

/usr/bin/python3 scripts/run_tum_rgbd_pilot.py \
  --publish-site

Raw data stays in the ignored data/raw/ directory. The command writes the report, CSV, figures, and the compact real-data video used on this page.

Claim boundary

This pilot has no human or robot collision labels. Its connectivity labels are defined on a fused geometric reference map. It is evidence that the real-data path runs end to end, not evidence that ConPath is already ready for ICRA/IROS.
